# CyberCrowd Core Header Law

IT REF: CC-CORE-HDR-0001

## Purpose

Every CyberCrowd Core file must answer what it is before it does anything.

The header protects the system from loose code, hidden lanes, route leakage, crawler maps, phishing help, bot invitation, and JS monster growth.
