# CyberCrowd Core Organ Law

IT REF: CC-CORE-ORG-0001

## Purpose

Define the CyberCrowd Core organs before implementation.

This file does not expose live URLs, private routes, token paths, endpoint maps, deployment paths, provider secrets, or attack surfaces.

It defines what each organ owns.

---

## Rule

Every core function must belong to an organ.

If a function does not belong to an organ, it does not enter Core.

---

## HALO

HALO is the guide and room signal.

### Owns

- Room context
- Safe guidance
- Next-action signal
- Human-readable direction
- Mission framing

### Does Not Own

- Transport
- Login
- Tokens
- Endpoints
- Private routes
- Tracking

---

## Secretary

Secretary routes lanes and keeps order.

### Owns

- Allowed movement
- Denied movement
- Lane decision
- Authority check
- Order of operations
- Stop / continue decisions

### Does Not Own

- UI
- Crawling
- Public route exposure
- Hidden sync
- Tracking

---

## Biff

Biff asks the point.

### Owns

- Purpose check
- Junk prevention
- “What’s the point?”
- Work-before-movement filter

### Does Not Own

- Punishment
- Ranking people
- Surveillance
- Authority by itself

---

## Dewey

- Lane match

### Does Not Own

- Tracking people
- Public route maps
- Uploads

## CLEAR / Value Law

Harvest only non-lethal, non-private, non-violating operational signal.

Use it for the point.

CLEAR the trail.

Keep the value.

The ping can disappear.

The value remains.
